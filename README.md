# 土壤磷素概念图 · 交互式网页

把 `graph_data.json` 里的 17 个节点、50 条无向关联边、290 条文献证据渲染成一个可点击的概念图。

## 快速开始

2026-11-12 已部署到Github pages。

本地调试：

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。


## 怎么用

- **点节点**：高亮该节点和它的所有关联边，右侧栏列出这些边。
- **点边**：右侧栏显示该边的证据卡片，按论文分组。每组 5 条以内全展示，超过 5 条先显示 3 条，点「展开更多」看剩下的。
- **再点一次**已选中的节点或边：取消选中。
- **点空白处**：清除选中，回到图例。
- **悬停长标签节点**（例如 `Fe/Al oxides (oxalate-extractable)`）：浏览器原生 tooltip 显示完整名称。
- **筛选关系**：在右侧筛选卡开关 `+` / `-` / `0` 极性，并选择证据条数下限（全部、≥2、≥3、≥5）；点「重置」恢复默认。`N/50` 表示当前可见边数 / 数据集总边数，隐藏边不会渲染。

极性配色：绿 `+` 正相关，红 `-` 负相关，灰 `0` 方向未定。
